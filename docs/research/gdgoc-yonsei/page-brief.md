# GDGoC Yonsei English homepage

- Source: https://gdgoc.yonsei.ac.kr/en
- Local routes: `/en` and `/` (root template homepage replacement)
- Scope: English homepage and four public navigation archives (`/en` and `/`; `/en/session`, `/en/project`, `/en/calendar`, `/en/member` are local routes).
- Visual system: near-black #101010 canvas, fine 5px dotted texture in hero, off-white typography, gray secondary text, thin white borders, rounded pill navigation/cards. Arial-like sans for display/body and monospace eyebrow/stat labels.
- Desktop: fixed translucent rounded navigation at 3% side inset, 56px high; centered hero fills viewport; title/mark, description, two pill links; four small stats and “SCROLL TO OPEN” at bottom. Main content has two-column intro, GDG information panel and three value cards, then four-column footer.
- Mobile: fixed nav collapses to brand + hamburger; menu opens full-screen with large links; hero content narrows, stats wrap; intro stacks and value cards form a vertical list; footer becomes two columns.
- Content: full visible English homepage, including Programs, Six parts, Latest sessions, Latest projects, Build with us, and footer.
- Assets: source font files and logo at `public/sites/gdgoc-yonsei/`; project previews in source order (FindFest, BlueNote, P-scheduler); Korea/Japan flag illustration extracted from the source inline SVG. Source asset URL mappings are documented by filenames: `font-display.woff2` = Google Sans Flex, `font-body.woff2` = Google Sans 700, `font-korean.woff2` = Google Sans Code, `gdgoc-logo.png` = site logo. Project images are source Next image URLs for the matching project entries.
- Motion: manifesto words transition from muted gray to white based on scroll progress and reverse naturally; reveal cards fade/translate in when entering the viewport; navigation opens full-screen with staggered links and line animation, closes with the close button or Escape, and locks page scroll; header color line follows document progress; CTA/session/project cards animate on hover; reduced-motion preferences disable entry transitions.
- Evidence: desktop and 390×844 mobile views, source scrolled manifesto/program/part/session/project sections, mobile menu open, local desktop/mobile/menu and scroll text checked. Remaining approximation: individual program cards use a tidy vertical sequence with colored borders and symbolic badges; source cards have denser custom compositions and more elaborate scroll timing. See `animation-inventory.md`, `asset-map.md`, `route-map.md`, and `qa-report.md` for current evidence and limitations.
